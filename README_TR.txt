AKRATĒS — Herkese açık sayfalar (17.11.2026)

İÇERİK
- index.html : Ana sayfa (Google OAuth Branding için taslak ana sayfa)
- privacy.html : Türkçe/İngilizce gizlilik politikası
- data-deletion.html : Türkçe/İngilizce veri silme yönergeleri
- .nojekyll : GitHub Pages yapılandırması

GITHUB PAGES KURULUMU
1. github.com hesabına giriş yap.
2. New repository: akrates-site, Public, Create repository.
3. Add file > Upload files bölümünde index.html, privacy.html, data-deletion.html ve .nojekyll dosyalarını yükle. Commit changes.
4. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. Yayımlanan URL'yi Settings > Pages bölümünde kontrol et. URL kullanıcı adına göre değişir; önceden varsayma.
6. Ana sayfanın ve privacy.html'nin giriş yapmadan açıldığını özel pencerede doğrula.

UYARI
- Bu metin gerçek çalışan uygulamaya göre hazırlanmış bir yayın öncesi taslaktır. Yasal/KVKK uygunluğu ve son sürüm veri akışları yayın öncesinde doğrulanmalıdır.
- Bulut yedeği silme düğmesi henüz uygulamada bulunmuyor. Uygulamada ve çevrimiçi sayfada silme süreci tamamlanmadan mağaza başvurusu yapmayın.
- Google OAuth Production doğrulamasında site alan adının sahipliğinin doğrulanması istenebilir. GitHub Pages alt alan adı bunun için tek başına yeterli olmayabilir; gerektiğinde size ait alan adı gerekir.
- Destek hesabına geçici verilen Google Cloud Editor (Legacy) rolünü, support email seçimi kaydedildikten sonra kaldırın. OAuth destek e-postasının görünürlüğünü kontrol edin.
- Kullanıcı adı bilinmediği için kesin bir web URL'si üretilemez.
